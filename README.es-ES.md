> #### Introducción
- JDK >= 1.8 (Este software se basa en la versión 1.8; las dependencias de terceros dependen de la versión de JDK que requieran)

    ```
    Esta es una biblioteca de dependencias de soporte para desarrollo rápido, diseñada para encapsular funcionalidades comunes, y se utiliza para desarrollo rápido o pruebas sin depender de grandes frameworks.
      
    toolkit se basa completamente en las funciones proporcionadas por JDK.
      
    toolkit3d encapsula otras funciones de utilidad comunes, ofreciendo un API más conciso.
    ```

- Obtención mediante Maven

  ```xml
  <dependency>
    <groupId>com.thankjava.toolkit</groupId>
    <artifactId>fast-toolkit</artifactId>
    <version>2.0.6</version>
  </dependency>
  ```

  ```xml
  <dependency>
    <groupId>com.thankjava.toolkit3d</groupId>
    <artifactId>fast-toolkit3d</artifactId>
    <version>2.0.6</version>
  </dependency>
  ```
